## 为什么 on-policy RL 是 0

fixture 没有：

```text
MODEL_TOKEN_IDS
MODEL_LOGPROBS
```

并且 researcher 没有显式 agent-level reward ownership，fixture 也没有显式 credit assignment。系统因此拒绝把两个 Agent 的 trace 宣称为 on-policy RL candidates。

## V2.2 边界

当前实现解决的是：

```text
如何从 explicit metadata 构建可审计的 multi-agent graph
如何按 Agent 生成 conservative training view
```

当前没有声称已经解决：

- 任意真实 Harness 的 multi-agent schema；
- 自动 credit assignment；
- shared reward 分解；
- 并发 branch 的完整语义；
- multi-agent rollout 到 trainer 的最终投影；
- 大规模 multi-agent benchmark 提升。

没有真实 multi-agent artifact 时，缺失字段继续标记为 `NOT_OBSERVABLE` 或 `INSUFFICIENT_EVIDENCE`。
