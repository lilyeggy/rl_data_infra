- run/episode 分区；
- event_id global idempotency；
- exact duplicate replay；
- conflicting event quarantine；
- append/flush/fsync；
- atomic partition manifest；
- reload/read-back；
- batch ingestion；
- shared-filesystem multi-process lock；
- raw-first manifest recovery；
- replaceable `StorageBackend` boundary；
- bounded queue/backpressure；
- raw-first derived compaction；
- explicit schema migration registry；
- deterministic ingestion latency summary；
- bounded HTTP ingestion baseline (`POST /v1/events`, `/healthz`, `/metrics`)。

## HTTP container baseline

可运行：

```bash
python3 -m src.cli serve-storage --root artifacts/v2.3-http-storage --host 0.0.0.0 --port 8080
```

HTTP service 使用 bounded queue 和后台 ingestion worker；schema invalid 返回 400，backpressure 返回 429。当前没有 auth/TLS/remote object storage，仍需云平台边界补齐。

## 当前 V2.3 边界

当前实现明确是：

```text
process-local-durable-filesystem
```

它没有声称：

- distributed exactly-once；
- multi-writer transactional commit；
- object-store atomicity；
- cross-region durability；
- production multi-tenant service。

V2.3 后续会将 local `StorageBackend` 替换为 object-storage/transactional adapter，而不是改变 canonical event、Episode、lineage 或 quarantine semantics。
