系统全景

一个完整 Agentic RL 系统同时包含 Agent 环境循环和模型学习循环。模块之间传递的不只是文本，还包括 token IDs、logprobs、工具结果、patch、reward、policy version 和模型权重。

输入 任务、环境状态、旧策略与训练配置
输出 新轨迹、可验证奖励与更新后的策略

它不负责什么

  • 没有任何单一组件独自完成整个 Agentic RL。

四个最容易混淆的边界

  • Harness ≠ 模型：Harness 决定下一步行动，模型只响应一次推理请求。
  • Polar ≠ SGLang：Polar 组织 Agent session，SGLang 计算 token。
  • Slime ≠ Megatron：Slime 组织 RL 流程，Megatron执行参数更新。
  • Reward ≠ Loss：测试得到 session reward，训练器再把它变成 token-level policy loss。
  • Harness 日志 ≠ 训练轨迹：训练还需要精确 token、old logprobs、loss mask、reward evidence 与 policy version。
